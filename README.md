# ghy3814_interactmap
This interactive web map visualizes the total Olympic medals won by countries at the Paris 2024 Summer Olympics. The purpose of the application is to provide a clear, fun, and geographically accurate representation of medal distribution across the world. Users can explore medal counts by hovering over countries to view popups with detailed information. I decided to do the 2024 Olympic medal distribution as a proportional symbol map to really show people the diffrence in medals won by each country to really emphasis the diffrence in the coutries atheletes.
